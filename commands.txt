import pandas as pd
from google.colab import files

# Upload file
uploaded = files.upload()

# Read Excel file directly
df = pd.read_excel(list(uploaded.keys())[0])

df.info()
df.describe()


Checking Missing & Duplicate Values
df.isnull().sum()
df.duplicated().sum()


Shows how many missing values
Shows how many duplicate rows

2. Removing Duplicates
df.drop_duplicates(inplace=True)


Removes duplicate rows permanently (because inplace=True)

3. Removing & Filling Missing Values
Remove NA rows
df.dropna()


This does NOT change the DataFrame unless you use:

df.dropna(inplace=True)

Fill all missing values with text
df.fillna("no data")


Does NOT change DataFrame unless:

df.fillna("no data", inplace=True)

Fill Age missing values with its mean
avg = df['Age'].mean()
df['Age'].fillna(avg, inplace=True)

Fill Marks missing values with zero
df['Marks'].fillna(0, inplace=True)

Replace remaining missing values
df.fillna("No name", inplace=True)

4. Save cleaned DataFrame to CSV
df.to_csv("output.csv", index=False)
files.download("output.csv")


Exports cleaned data
Downloads CSV in Google Colab
